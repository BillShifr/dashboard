# Dashboard — продуктовая спецификация

Самостоятельная система редактора карт Югры для презентационных материалов ТФОМС.
Разворачивается на `dashboard.tfoms`, независимо от HR и других внутренних систем.

## Принятые решения

1. В v1 входят оба продукта: **редактор территорий** и **диспансеризация**.
2. Хранение макетов — **серверные пресеты** (PostgreSQL), не только localStorage.
3. Production-хост: `http://dashboard.tfoms`.

## Назначение

Редактор строит географическую схему, шестиугольники и карту медучреждений;
пользователь задаёт цвета/значения (или план/факт), сохраняет именованный пресет
и экспортирует PNG/PDF для докладов.

## Роли

| Роль     | Права                                              |
| -------- | -------------------------------------------------- |
| `viewer` | Просмотр пресетов, экспорт                         |
| `editor` | Создание/правка своих и общих пресетов организации |
| `admin`  | Пользователи, все пресеты, сброс                   |

## Типы пресетов

| `kind`             | Источник UX                  | Payload version |
| ------------------ | ---------------------------- | --------------- |
| `territory`        | «Югра — редактор территорий» | `territory-v1`  |
| `dispanserization` | «Югра · Диспансеризация»     | `disp-v5`       |

Payload валидируется Zod на сервере. Невалидный JSON не сохраняется.
