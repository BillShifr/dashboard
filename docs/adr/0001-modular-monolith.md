# ADR-0001: модульный монолит

Статус: принят.

## Решение

Одно Next.js-приложение с PostgreSQL. Доменные модули: auth, presets, territory,
dispanserization, export. Связь через сервисы и Zod-схемы payload.

## Причины

Микросервисы избыточны. Нужен тот же ops-контур, что у HR, без копирования кадрового домена.

## Следствия

Запрещены прямые зависимости UI от таблиц. Изменения пресетов идут через
`domain/presets/service` с проверкой прав, optimistic version и audit.
